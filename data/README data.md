# data/ — исходные данные каталога

Здесь лежат CSV-файлы, из которых наполняется база данных Supabase.
Это **источник правды** для каталога: сначала правим CSV, потом загружаем в базу.

## Файлы

| Файл | Таблица в Supabase | Строк | Назначение |
|---|---|---|---|
| `categories.csv` | `categories` | 7 | Категории изделий |
| `products.csv` | `products` | 69 | Товары каталога |

## Формат

- Кодировка: **UTF-8** (в Excel — «CSV UTF-8 (разделитель — запятая)»)
- Разделитель: **запятая**
- Первая строка: названия колонок
- Тексты с запятыми внутри — в двойных кавычках: `"Кулон ""Звезда"", малый"`

## categories.csv

| Колонка | Тип | Пример | Комментарий |
|---|---|---|---|
| `slug` | текст | `runy` | латиницей, уникально, используется в адресах |
| `name` | текст | `Руны` | название на сайте |
| `description` | текст | `Руны из эпоксидной смолы` | может быть пустым |

Поле `id` в CSV **не заполняется** — база присваивает его сама.

## products.csv

| Колонка | Тип | Пример | Комментарий |

## Соглашение по артикулам

Артикулы в каталоге распределены по категориям префиксом — так удобно искать глазами:

| Префикс | Категория | Количество |
|---|---|---|
| `00xxx` | Руны | 3 |
| `01xxx` | Шахматы | 1 |
| `10xxx` | Брелоки | 8 |
| `20xxx` | Куклы | 2 |
| `30xxx`, `31xxx` | Подвески | 48 |
| `40xxx` | Кольца | 4 |
| `50xxx` | Подвески | 1 |
| `60xxx` | Игр. кости | 2 |

> **Требует решения:** товар `#50001 «Кровавый лед из эпоксидной смолы»` имеет префикс
> `50xxx`, но отнесён к категории «Подвески». Либо префикс `50xxx` должен означать
> отдельную категорию, либо артикул нужно перенести в диапазон `3xxxx`.

## Как загрузить CSV в базу

**Supabase → Table Editor → нужная таблица → Insert → «Import data from CSV»**

Перед импортом сделайте резервную копию: **⋯ → Download data to CSV**.

## Порядок загрузки

1. Сначала `categories.csv` — чтобы появились `id` категорий.
2. Затем `products.csv` — ему нужны готовые `category_id`.

Если грузить наоборот, `products` не найдут свои категории.
