Условия заказа

Напишите нам в личные сообщения — это самый простой и быстрый способ начать. Сделать это можно так:

  • • через кнопку «Сообщение» на главной странице PaprekolyX;
  • • через кнопку «Написать» в карточке любого товара.

В диалоге вам ответит администратор: уточнит детали, ответит на вопросы и поможет определиться с выбором.

Написать ВКонтакте

Выбирайте удобный для вас способ:

  • • Онлайн-корзина ВКонтакте — оплата через VK Pay.
  • • Перевод на карту — Сбербанк (МИР) или Яндекс Банк (МИР) по номеру счёта.
  • • СБП — перевод по номеру телефона через Систему быстрых платежей.

Если вы не уверены, какой вариант вам подходит, администратор подскажет в переписке.

02. Структура базы данных

Реляционная БД PostgreSQL. Ниже — основные сущности и связи.

products
Товары
id SERIAL PRIMARY KEY
article VARCHAR(20) UNIQUE — внутренний артикул
name VARCHAR(255) NOT NULL
price DECIMAL(10,2) NOT NULL
category_id INT REFERENCES categories(id)
description TEXT
image_url VARCHAR(500)
stock INT DEFAULT 1
is_active BOOLEAN DEFAULT TRUE
created_at TIMESTAMP
categories
Категории
id SERIAL PRIMARY KEY
slug VARCHAR(50) UNIQUE
name VARCHAR(100) NOT NULL
description TEXT
users
Пользователи
id SERIAL PRIMARY KEY
email VARCHAR(255) UNIQUE
password_hash VARCHAR(255)
full_name VARCHAR(200)
phone VARCHAR(20)
role VARCHAR(20) DEFAULT 'customer'
created_at TIMESTAMP
orders
Заказы
id SERIAL PRIMARY KEY
user_id INT REFERENCES users(id)
status VARCHAR(30)
total DECIMAL(10,2)
delivery_address TEXT
contact_phone VARCHAR(20)
comment TEXT
created_at TIMESTAMP
order_items
Позиции заказа
id SERIAL PRIMARY KEY
order_id INT REFERENCES orders(id) ON DELETE CASCADE
product_id INT REFERENCES products(id)
quantity INT NOT NULL
price DECIMAL(10,2)

id SERIAL PRIMARY KEY
user_id INT REFERENCES users(id) ON DELETE CASCADE
product_id INT REFERENCES products(id)
quantity INT DEFAULT 1
UNIQUE(user_id, product_id)

03. Основные пользовательские пути

1
Просмотр каталога
Пользователь открывает главную → прокручивает до секции «Коллекция» → видит сетку товаров с изображениями, названиями и ценами. Может фильтровать по категориям.
2
Добавление в корзину
Клик по кнопке «В корзину» → товар добавляется в локальное состояние → счётчик в шапке увеличивается → появляется toast-уведомление.
3
Управление корзиной
Клик по иконке корзины → открывается боковая панель → пользователь может менять количество (+/−), удалять позиции. Итоговая сумма пересчитывается автоматически.
4
Оформление заказа
Клик «Оформить через VK» → редирект в сообщество ВКонтакте → пользователь пишет в сообщения → администратор уточняет детали, принимает оплату → оформляет доставку.
5
Связь с мастером
Пользователь переходит в секцию «Контакты» → выбирает ВКонтакте, email или телефон → связывается для кастомного заказа или консультации.

Правила использования

✓
Допустимо
  • • Использовать логотип на тёмном фоне с неоновым свечением
  • • Применять градиенты розовый-фиолетовый для акцентов
  • • Использовать шрифт Cormorant Garamond для заголовков
  • • Добавлять эффект свечения (text-shadow) для ключевых элементов
✗
Недопустимо
  • • Использовать логотип на светлом фоне без контрастной обводки
  • • Менять цвета логотипа на другие, кроме указанных в палитре
  • • Растягивать или искажать пропорции логотипа
  • • Использовать другие шрифты для заголовков
