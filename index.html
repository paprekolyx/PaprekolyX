там, где застывает время

Украшения, брелоки и аксессуары из эпоксидной смолы и фетра. Мы специально не выгоняем из смолы каждый пузырёк воздуха и не ищем два одинаковых оттенка — именно они делают изделие узнаваемым.

✨
Неповторимость
Смола застывает по своим правилам: пигмент расходится неравномерно, сухоцветы ложатся под собственным весом. Повторить узор второй раз не получится даже у нас — поэтому каждое изделие существует в одном экземпляре.
✨
Индивидуальность
Цвет, форма и наполнение — на ваш выбор. Опишите, что хотите получить: подберём пигменты и вставки, согласуем эскиз и рассчитаем стоимость.

Витрина + заказ

Авторская мастерская изделий из эпоксидной смолы и фетра. Сайт работает как витрина с корзиной и формой заказа; детали, оплата и доставка подтверждаются в переписке сообщества ВКонтакте. Полная редакция документа — в репозитории.

01.

Стек технологий

Клиент
  • • HTML5 — одна страница index.html
  • • CSS3 + Tailwind CSS через CDN
  • • JavaScript ES6+, без сборки
  • • Шрифты Cormorant Garamond и Inter
  • • Корзина и тема — в localStorage
Сервер и данные
  • • Supabase — PostgreSQL, RLS, функции
  • • Клиент @supabase/supabase-js v2
  • • Приём заказов — функция create_order()
  • • GitHub Pages + GitHub Actions
  • • Фото — Cloudinary или Supabase Storage
Серверного кода на отдельном хостинге нет. Вся серверная логика живёт внутри Supabase: политики RLS решают, кто и какие строки может прочитать, а функция create_order() принимает заказы и пересчитывает суммы на стороне базы. Отдельный бэкенд проекту не нужен.
02.

Архитектура

GitHub Pages · index.html → Supabase · PostgREST + RLS → Сообщество ВКонтакте

Заказ создаётся не прямым INSERT из браузера, а вызовом серверной функции. Функция сама берёт цены из таблицы products, поэтому подменить стоимость через консоль браузера нельзя. Одновременно создаются записи в четырёх таблицах: заказ, позиции, доставка и журнал статусов.

Защита внутри create_order
  • • цены берутся из базы, присланные игнорируются;
  • • одна транзакция на заказ и все его позиции;
  • • заказать можно только активные товары;
  • • количество от 1 до 99, не более 50 позиций;
  • • не более 3 заказов за 10 минут с одного контакта.
Клиентская сторона
  • • все выводимые тексты экранируются (защита от XSS);
  • • повторная отправка формы блокируется;
  • • в браузере только публичный ключ Supabase;
  • • секретный ключ не хранится в репозитории.
05.

Пользовательские пути

1
Просмотр каталога
Главная → секция «Коллекция». Товары и категории читаются из Supabase, на кнопках категорий показано число изделий.
2
Корзина
«В корзину» → счётчик в шапке → боковая панель: количество, удаление, пересчёт суммы. Корзина сохраняется в браузере и не пропадает при обновлении.
3
Оформление заказа
«Оформить заказ» → форма с контактами, оплатой и доставкой → вызов create_order() → экран с номером заказа → переход в сообщения сообщества.
4
Кастомное изделие
«Обсудить в ВК» → переписка с мастером → предоплата 40% → изготовление → доплата → отправка.
5
Смена темы оформления
Переключатель в шапке → светлая или тёмная тема. Выбор запоминается, при первом визите берётся из настроек системы.

Почему акцент в светлой теме темнее
Фирменный розовый #FF2D95 на белом фоне даёт контраст всего 3.46:1 — это ниже нормы WCAG AA для обычного текста (4.5:1). Поэтому в светлой теме используется #D6006E — тот же розовый, но затемнённый до 5.14:1. Фиолетовый по той же причине меняется с #A855F7 (3.96:1) на #7C3AED (5.70:1). Оттенок бренда узнаваем, читаемость соблюдена.
Правила светлой темы
  • • Неоновое свечение (text-shadow) отключается — на светлом фоне оно выглядит грязным пятном
  • • Тени смягчаются: вместо розового свечения — нейтральная тень rgba(108,60,150,.12)
  • • Полупрозрачные белые подложки заменяются на полупрозрачные тёмные
  • • Затемнение поверх фотографий и модальных окон остаётся тёмным в обеих темах
  • • Минимальный контраст текста — 4.5:1, для крупного текста — 3:1
Переключатель темы
  • • Размер 60 × 30 px, скругление полное, обводка розовая 32%
  • • Внутри — два значка: солнце слева, луна справа
  • • Бегунок 22 px с фирменным градиентом, переезд за 0.38 с
  • • Активный значок подсвечивается белым
  • • Есть aria-label и видимый фокус с клавиатуры
  • • Тема применяется до отрисовки страницы — без «вспышки» другого цвета

Кириллица обязательна

Это правило относится ко всем текстам сайта, а не только к техническим подписям. Каждый подключаемый шрифт обязан содержать и кириллицу, и латиницу в едином стиле. Если русских букв в шрифте нет, браузер подставит для них другой шрифт, и смешанный текст вроде «арт. 00099» будет выглядеть разнобоем — буквы разной высоты и насыщенности.

Сейчас на сайте три шрифта, все с кириллицей: Cormorant Garamond, Inter и JetBrains Mono.

Правила использования

✓

  • • Растягивать или искажать пропорции логотипа
  • • Использовать другие шрифты для заголовков
