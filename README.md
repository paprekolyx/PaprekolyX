# PaprekolyX

Авторская мастерская: изделия ручной работы из эпоксидной смолы и фетра.
Сайт-витрина с корзиной и формой заказа. Общение с клиентом и оплата —
через сообщество ВКонтакте.

**Сайт:** https://paprekolyx.github.io/PaprekolyX/
**Сообщество ВК:** https://vk.ru/paprekolyx

---

## Стек

| Слой | Технология |
|---|---|
| Вёрстка | HTML5, CSS3, JavaScript ES6+ |
| Стили | Tailwind CSS (CDN), две темы оформления |
| Шрифты | Cormorant Garamond, Inter |
| База данных | Supabase (PostgreSQL + RLS + серверные функции) |
| Хостинг | GitHub Pages (GitHub Actions) |

## Как вносить изменения в сайт

1. Отредактируйте `index.html`.
2. Загрузите файл в репозиторий: **Add file → Upload files**.
3. GitHub Actions опубликует сайт за 1–2 минуты.
   Прогресс: https://github.com/paprekolyx/PaprekolyX/actions
4. Откройте сайт и обновите страницу с очисткой кеша: **Ctrl + F5**.

Проверить разметку до загрузки можно локально: откройте `index.html`
двойным щелчком — он запустится в браузере прямо с диска.

## Как вносить изменения в базу

**Тексты, контакты, цены доставки, логотип и промо-картинка** правятся без кода:
Supabase → Table Editor → таблица `site_content`.

**SQL-скрипты** из папки `supabase/` выполняются в Supabase → SQL Editor →
New query → Run. Все скрипты идемпотентны: их можно запускать повторно.
Порядок применения — по номерам файлов.

**Товары и категории** обновляются через Table Editor → Insert →
«Import data from CSV». Перед импортом сделайте резервную копию:
⋯ → Download data to CSV.

## Зависимости

Библиотека Supabase лежит в `assets/supabase.min.js` и загружается с того же
адреса, что и сайт. Это намеренно: сторонние CDN (jsdelivr, unpkg) периодически
недоступны у отдельных провайдеров, а без библиотеки каталог не загрузится.
Если локальный файл по какой-то причине не отдан, страница подключает запасной
источник с jsdelivr.

Tailwind CSS и шрифты пока подключаются с CDN — это влияет только на внешний вид,
но не на работу каталога и приём заказов.

**Важно:** при загрузке обновлений не забывайте про папку `assets/`.

## Безопасность

- В `index.html` лежит только **публичный** ключ Supabase (`sb_publishable_…`) —
  так и должно быть: доступ ограничивает Row Level Security.
- **Секретный** ключ (`sb_secret_…` / `service_role`) нельзя помещать ни в один
  файл репозитория. Репозиторий публичный.
- Заказы создаются серверной функцией `create_order()`, которая берёт цены
  из базы. Подменить стоимость из браузера нельзя.
- Промокоды закрыты для публичного чтения.

Подробнее — в `SECURITY.md` и в разделе 7 технического паспорта.
